# ModernCalc - Kalkulator Modern Web

**ModernCalc** adalah kalkulator web dengan desain futuristik dan pengaturan yang fleksibel & responsif, dikembangkan oleh **Alff Senpai & Saka.dlv**. Kalkulator ini dirancang untuk memberikan pengalaman perhitungan yang intuitif dengan fitur-fitur canggih seperti riwayat otomatis, kontrol keyboard penuh, dan opsi penyesuaian tema serta tampilan.

## ✨ Fitur Utama

- **Perhitungan Real-Time**: Menampilkan hasil perhitungan secara langsung saat mengetik ekspresi.
- **Riwayat Hasil Otomatis**: Simpan dan akses riwayat perhitungan sebelumnya dengan mudah.
- **Kontrol Penuh Keyboard**: Dukungan input melalui keyboard untuk efisiensi maksimal.
- **Tema Unik**: Pilih antara tema Default, Light, atau Dark untuk menyesuaikan tampilan.
- **Penyesuaian Font dan Bentuk Tombol**: Ubah ukuran font (20-60px) dan bentuk tombol (Default, Bulat, Kotak).
- **Operasi Matematika Lengkap**: Mendukung penjumlahan, pengurangan, perkalian, pembagian, persentase, dan tanda kurung.
- **Desain Responsif**: Tampil optimal di berbagai ukuran layar dan orientasi.
- **Animasi dan Efek Visual**: Transisi halus, efek hover, dan animasi untuk pengalaman interaktif.
- **Panel Pengaturan dan Tentang**: Akses mudah ke pengaturan dan informasi aplikasi.

## 🚀 Cara Menggunakan

1. **Unduh atau Clone Repository**:
   ```
   git clone https://github.com/Alfareza26/moderncalc.git
   cd moderncalc
   ```
   
   Atau menggunakan Link pada bagian **About**

2. **Buka di Browser**:
   - Buka file `index.html` langsung di browser web favorit Anda (Chrome, Brave, Edge, dll.).

3. **Mulai Menggunakan**:
   - Klik tombol "Mulai" pada overlay sambutan.
   - Gunakan tombol kalkulator atau keyboard untuk input ekspresi.
   - Tekan "=" atau Enter untuk menghitung hasil.
   - Akses pengaturan dengan klik ikon roda gigi di kanan atas.

## 🎮 Kontrol Keyboard

- **Angka dan Operator**: Ketik langsung angka (0-9), operator (+, -, x, :, %), dan titik desimal (.).
- **Enter**: Hitung hasil (=).
- **Backspace**: Hapus karakter terakhir (⌫).
- **C**: Hapus semua (AC).

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur dasar aplikasi.
- **CSS3**: Styling dengan variabel CSS, animasi, dan responsivitas.
- **JavaScript (ES6+)**: Logika kalkulator, event handling, dan interaktivitas.
- **Google Fonts**: Font "Noto Sans JP" dan "Momo Signature" untuk tampilan estetik.
